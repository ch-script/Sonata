## VERSION 0.2

### What's new?

- **Custom scripts & extensions**: You can now write your own scripts or extend the existing ones. To unlock this, you first need to allow customs on your system:

```bash
  snt --allow customs
```

  Once you run that, `snt` will spit out a path, go there and start editing the files. Check [CONFIG.md](./CONFIG.md) to see the naming/syntax you need to follow.

- **Bluetooth config support (Linux)**: You can now manage your bluetooth setup straight from `snt` instead of jumping between random tools.

- **`snt --profile`**: Shows you system info at a glance. Want everything? Run it with `--verbose`:

```bash
  snt --profile --verbose
```

  Only need one specific thing? Pass an id after it, like this:

```bash
  snt --profile --verbose --wm
```

  All of this data is stored inside a TOML file in your `.config` folder, easy to poke around if you're curious.

- **Variable support**: This is probably the highlight of 0.2. You can now set variables for your environments so you stop having to remember/type the same stuff over and over. Set one like this:

```bash
  snt --add-var <variable_name> "variable text" --target <module> <specific_module_component> --assign
```

  `--assign` is optional. If you use it, `snt` just assumes whatever variable is currently assigned for that spot. For example, instead of typing:

```bash
  snt edit write path
```

  you can just do:

```bash
  snt edit write
```

  and it'll grab the `path` variable automatically.

- **Nix support leveled up**: The declarative system is way more mature now and can handle more than one package at a time. On top of that, `snt` now supports both declarative and imperative approaches for Nix, so pick whichever fits your workflow.

- **Initial OpenRC & Gentoo compatibility**: Early support is in, more polish coming as we go (and as I learn how to even use Gentoo lol)
