# Customs and Development Environments

- Expand Customs into a system for managing reusable configurations and development utilities.

- Allow users to download predefined utility collections through commands such as:

```bash
snt customs get Python
```

- Introduce support for external configuration files through an include mechanism.

- Allow downloaded utilities and configurations to be incorporated into existing Customs definitions.

- Automate development environment preparation, including virtual environments and required dependencies.

- Simplify language-specific workflows so users do not need to remember complex environment setup procedures.

- Introduce commands such as:

```bash
snt python env .
```

- Automate environment activation, interpreter configuration, and execution where appropriate.
